## Background/Content

**ISO 19144-2** Land Cover Meta Language (LCML) and **ISO 19144-3** Land Use Meta Language (LUML) are
two standardization projects that provide a controlled vocabulary for
machine-readable and machine-interpretable classification systems. **ISO 19144-2** was newly published
at the end of 2023. The planned release date for **ISO 19144-3** is mid-2024. After its finalization, 
the work on **ISO 19144-4** will start.

For ISO **19144-2**, the so-called LChS Software (**L**and **CH**aracterization **S**ystem)
exist which allows the definition Land Cover Classes based in the  **ISO 19144-2** . 
Unfortunately, **ISO 19144-3** is not currently implemented. However, plans are in place to integrate it into the LChS, which
will enable aspects of land use to be taken into account in class descriptions.

Using controlled vocabularies for the documentation of the classification systems of
the Copernicus Land Monitoring products significantly increase their semantic
interoperability, supporting data integration and the necessary exchange
between the various domain-specific EU data spaces under development.

To provide these machine-readable land cover and land use nomenclature
descriptions, they will be published in a so-called register. The technical
specification for this register is being developed as part of the new **ISO 19144-4** standardization project,
scheduled to start in 2025.

Participation in standardisation projects and their revisions provides an
opportunity to consider certain EAGLE aspects when creating new standards and
revising existing ones. Additionally, it facilitates the exchange of knowledge
regarding the design of land cover and land use vocabularies, which is
essential for adapting EAGLE concepts for practical application.

## Goals of harmonisations issues between EAGLE & ISO vocabulary

* **Provision** of ISO-compliant documentation of
European land cover and land use nomenclatures documented based on the EGALE
model: The EAGLE Matrix and the so-called barcoding method is currently used to
document European land cover and land use nomenclatures. The establishment of a
semantic transformation enable the conversion of land cover and land use
documentations available in the EAGLE matrix into ISO-compliant documentations.

* **Registration** of European land cover and land use nomenclatures in the FAO Land
Cover Registry: Once the above transformation into an ISO standard-compliant
documentation has been completed, the nomenclatures can be made available in
the official FAO Land Cover Registry.

* Use of **ISO standard-compliant nomenclatures**: By
establishing a crosswalk from ISO to the EAGLE concepts, the use of
standardized nomenclatures in software based on the EAGLE concepts, such as the
[CLCplus Core Service](https://clcplus-core.land.copernicus.eu/), is facilitated.

* Use of **standard-compliant software**: Once semantic
interoperability between ISO and EGALE has been established, all software
products currently being developed based on ISO standards can also be used in
the EAGLE context.

* **Comparability of land cover and land use nomenclatures**:
By converting EAGLE-based nomenclatures into ISO format, they
become comparable and similarity values between class definitions can be
calculated. This function is currently also being implemented in existing land characterization
system software.

To this end, **initial tests** were first
conducted last year to convert land cover nomenclatures recorded using the
barcoding method and based on the EAGLE matrix into an ISO-compliant format
using LChS software. These tests revealed several **issues** relating to the
semantic harmonisation of ISO and EAGLE concepts. Despite pursuing very similar
objectives – defining land cover and land use classes as clearly, standardised
and machine-readably as possible – the two model approaches developed differ
significantly from each other in a number of respects. These differences stem
from the authors' very different technical expertise and the completely
different conceptual approaches they took. Further tests are required to
identify all issues that could be caused by incompatibilities between semantic
artefacts and model semantics.

## Recommendations

Based on these results, recommendations can be derived to maximise semantic compatibility between the ISO and EAGLE worlds.
These recommendations concern:

* The **adaptation** of certain **EAGLE concepts**
* **Proposals for the inclusion of missing concepts**, or changes to existing ones, as part of revising the ISO 19144 series of standards
* Additionally, possible **implementation concepts** outlined above.
